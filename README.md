# VeryFixation-Online-Document-Verifier-
 a document verification system developed to ensure the authenticity and integrity of digital files using cryptographic hashing. The system is implemented as a web-based application leveraging modem frontend technologies, including React and Framer Motion, to provide a seamless and user-friendly experience. 
System Requirements
• - Frontend Framework: React.js ( v 18)
• Styling: Tailwind CSS
• Animation: Framer Motion
• Icons: Lucide React
• Build Tool: Vite or Webpack
• Hashing: Web Crypto API (built into modem browsers)
