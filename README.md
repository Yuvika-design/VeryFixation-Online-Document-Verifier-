# VeryFixation-Online-Document-Verifier-
 a document verification system developed to ensure the authenticity and integrity of digital files using cryptographic hashing. The system is implemented as a web-based application leveraging modem frontend technologies, including React and Framer Motion, to provide a seamless and user-friendly experience. 
System Requirements
• - Frontend Framework: React.js ( v 18)
• Styling: Tailwind CSS
• Animation: Framer Motion
• Icons: Lucide React
• Build Tool: Vite or Webpack
• Hashing: Web Crypto API (built into modem browsers) 


# Document Verification App

A modern web application to **upload**, **preview**, and **verify documents** using SHA256 hash fingerprinting.

Built with **React**, **Tailwind CSS**, and **Node.js**, this app lays the foundation for both centralized and decentralized document verification systems (via backend or blockchain).

---

## Features

- Upload files via drag & drop or file picker
- Live preview for images, PDFs, audio, and video
- Generate SHA256 hash of each uploaded file
- Verify hash with backend for authenticity
- Clean, responsive UI with Tailwind CSS
